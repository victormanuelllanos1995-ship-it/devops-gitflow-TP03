# Gestión de Usuarios

Este documento detalla la gestión, creación y permisos de los usuarios del sistema.

## Scripts asociados
- `verificar-permisos.sh`: Script encargado de validar los permisos de ejecución y acceso de los usuarios en el sistema.

## Instrucciones de uso
1. Ejecutar el script principal.
2. Verificar los roles asignados.
